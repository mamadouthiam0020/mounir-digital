# MOUNIR DIGITAL — Site Vitrine

Site web vitrine de l'agence digitale **MOUNIR DIGITAL** : création de sites web, applications mobiles, marketing digital, branding et SEO.

## 🚀 Aperçu

Un site one-page moderne et responsive, réalisé en HTML / CSS / JavaScript pur (aucune dépendance).

## 📁 Structure du projet

```
MOUNIR_DIGITAL/
├── index.html       # Page principale (structure HTML)
├── styles.css       # Feuille de style (design, animations, responsive)
├── script.js        # Interactions JS (header, animations au scroll, formulaire)
└── assets/          # Images et ressources
    ├── logo_Mounir_DIGITAL.png
    ├── ndiouroul.png       # Visuel du projet Ndiouroul Voyages
    ├── samba.jpeg          # Photo équipe — Papa Samba Mboup
    ├── mamadou.jpeg        # Photo équipe — Mamadou THIAM
    └── cheikh.jpeg         # Photo équipe — Cheikh Abdou Sy
```

## 🎨 Design

- **Palette** : navy `#071A35`, bleu `#155EEF`, or `#D6A84F`, blanc
- **Typographie** : Sora (titres) + Inter (corps)
- **Animations** : révélations au scroll, cartes flottantes, marquee, hover effects

## ✨ Sections

- Accueil (héro avec statistiques et visuel animé)
- Services
- Expertise
- Équipe
- Réalisations (portfolio)
- Processus
- Contact (formulaire avec budget en FCFA)

## ▶️ Lancement

Ouvrir simplement `index.html` dans un navigateur :

```bash
start index.html   # Windows
```

Aucun serveur ni build nécessaire.

## 📬 Formulaire de contact

Le formulaire gère l'envoi côté client et affiche un message de confirmation. Les montants du champ budget sont exprimés en **FCFA**.
